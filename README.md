# Райдер служения

Приложение для звукарей и лидеров прославления: вносите состав на служение — и сразу видно,
сколько микрофонов, XLR и джек-кабелей, DI-боксов и стоек брать, плюс список каналов для пульта.

- Ставится на iPhone и Android по ссылке (Safari → «Поделиться» → «На экран „Домой“»).
- Команда входит по ссылке-приглашению, данные общие (Firebase Firestore).
- Работает без интернета, изменения досылаются, когда связь появится.

Открыть: https://moklyakj-crypto.github.io/rider-app/
